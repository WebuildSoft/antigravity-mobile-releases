### ⚡ Como Instalar
1. Baixe o arquivo APK diretamente no seu smartphone Android.
2. Se solicitado pelo navegador, toque em *"Permitir instalação de fontes desconhecidas"* ou *"Fazer download mesmo assim"*.
3. Toque na notificação de download concluído e clique em **Instalar**.
4. Inicie o app e conecte ao seu servidor Antigravity escaneando o QR Code na tela do seu computador.
